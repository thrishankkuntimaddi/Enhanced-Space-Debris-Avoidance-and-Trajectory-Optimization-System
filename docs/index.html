Capabilities

What this system does

🛰️

Real TLE Ingestion

Upload or paste live Two-Line Element sets from Space-Track.org. The system preprocesses and validates thousands of debris objects in seconds.

⚡

DDQL Optimization

A Double Deep Q-Learning agent learns to adjust the rocket's trajectory in real-time, minimizing collision probability while preserving orbital insertion.

🌍

3D Visualization

Interactive Plotly 3D globe renders the full trajectory — burn phase, coast phase, target ring, and collision markers — with playback animation.

📊

Mission Reports

Automatically generated text reports covering rocket params, trajectory equations, collision events, and post-optimization stats.

🔥

Firebase Analytics

Every session is tracked with Google Analytics and Firestore — mission outcomes, collision counts, and optimization effectiveness are logged in real-time.

🧪

Dummy TLE Testing

No Space-Track account? Generate synthetic collision-prone TLEs placed directly on your trajectory to test the full pipeline instantly.

Deployment

Get it live in 5 minutes

1

Push to GitHub

The repository is already configured. Run git push origin main to trigger the GitHub Actions workflow that publishes this page.

2

Deploy backend to Render

Go to render.com → New Web Service → connect this repo → Render auto-detects render.yaml and deploys the Flask app.

3

Set your backend URL here

Edit docs/index.html — replace YOUR_RENDER_URL with your Render deployment URL so the "Launch App" button points to the live backend.

4

Enable GitHub Pages

In your repo Settings → Pages → Source: Deploy from branch → Branch: main → Folder: /docs → Save.

5

Enable Firestore

In Firebase Console → Firestore Database → Create database → Start in test mode. Mission sessions will appear under the mission_sessions collection.
