// How to Obtain TLE Data

1. Visit space-track.org
2. Create a free account and log in
3. Navigate to Home → Recent ELSETs
4. Select a TLE dataset (e.g. "Julian Dates")
5. Select all → Copy → Paste here

Note: Larger datasets produce more accurate collision detection but take longer to process.
